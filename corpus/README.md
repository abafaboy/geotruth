# geotruth corpus

The inputs geotruth poses to geometry libraries, and the exact answers to them.

The case data and the expected answers in this directory are dedicated to the public domain
under **CC0 1.0** ([LICENSE](LICENSE)). GEOS (LGPL), JTS (EPL/EDL), Boost (BSL), Clipper2
(BSL) and any other project can copy cases into their own test suites without asking and
without attribution. The generator code in [`generators/`](generators/) is code, and like the
rest of the repository it is MIT-licensed ([../LICENSE](../LICENSE)).

## Layout

| path | what |
|---|---|
| [`cases/`](cases/) | case files, JSON Lines, one case per line. Only small tiers are tracked in git; generated files written here are ignored |
| [`cases/seed.jsonl`](cases/seed.jsonl) | the 1000-case smoke-test corpus of the bug hunt: 4 near-degenerate families × 250 (`generators/seed.py 250 1`) |
| [`expected-v1/`](expected-v1/) | expected answers, version 1: the legacy answers of the audited oracle (see below) |
| [`generators/`](generators/) | the case generators: ten near-degenerate families, the seed families, validation and the per-family pipeline ([README](generators/README.md)) |
| [`SHA256SUMS`](SHA256SUMS) | checksums of every tracked case and expected-answer file |

The oracle review's own case families are generated by
[`tools/oracle_review/gen_review.py`](../tools/oracle_review/gen_review.py), and Clipper2's
integer cases live with that adapter in
[`adapters/clipper2/int_cases.jsonl`](../adapters/clipper2/int_cases.jsonl).
[`harness/hunt.sh`](../harness/hunt.sh) gathers all of them for a round.

## Case format

Cases currently use format v1, specified in
[`harness/FORMAT-v1.md`](../harness/FORMAT-v1.md):

```json
{"id": "tiny-rotation-1-000001", "family": "tiny-rotation", "a": MULTIPOLYGON, "b": MULTIPOLYGON}
```

`a` and `b` are GeoJSON MultiPolygon coordinate arrays with closed rings. Each JSON number is
read the way a library reads it: it becomes an IEEE-754 double first, so an integer literal
above 2^53 rounds. The exact answer is the answer for those doubles, taken as rationals.

The design's case format ([DESIGN.md §3](../docs/DESIGN.md)), `{id, family, tags,
provenance, a, b}` with typed geometries of every OGC type, replaces v1 as the new engine
lands. v1 files stay valid: they are never rewritten, only superseded.

## Versioning

- **Cases are immutable.** A published case file is never edited. A fix is a new file or a
  new tier, and `SHA256SUMS` makes accidental edits visible.
- **Expected answers are versioned separately** from the cases, as `expected-vN/`, with
  errata released as new versions. Every claim cites the corpus version, the expected
  version and the engine commit.

### `expected-v1/`: legacy oracle answers

`expected-v1/seed.jsonl` holds the answers of the bug hunt's exact oracle, now vendored as
[`tests/reference/oracle.py`](../tests/reference/oracle.py), for `cases/seed.jsonl`. Each
line is a FORMAT-v1 result line with `"lib": "oracle"`:

- validity (`valid_a`, `valid_b`), the nine named predicates, the six areas as doubles, and
  the exact areas as rational strings under `exact` (`inter`, `diff_ab`, `diff_ba`);
- only `id`, `lib`, `valid_a` and `valid_b` when an input is invalid (nothing else is
  defined then).

It was produced by the oracle at commit `e16e757` (`oracle.py seed.jsonl`), and
re-running the vendored copy reproduces it byte for byte:

```sh
python tests/reference/oracle.py corpus/cases/seed.jsonl | cmp - corpus/expected-v1/seed.jsonl
```

These answers cover polygon/polygon predicates, validity and overlay **areas** only. Full
DE-9IM matrices and exact overlay geometry arrive with the geotruth engine as `expected-v2`.
